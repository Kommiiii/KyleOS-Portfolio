# Windows XP Inspiired Student Portfolio

A web-based portfolio simulating the Windows XP operating system environment, featuring interactive windows, taskbar navigation, and custom application themes.

Test it out here: https://kommiiii.github.io/KyleOS/

## Key Features
* **Custom OS Engine:** Vanilla JavaScript window manager (Z-indexing, dragging, taskbar tabs).
* **XP-Styled Applications:**
    * **Profile.doc:** MS Word 2003-themed bio.
    * **Portfolio.html:** Internet Explorer-themed showcase with category filtering and image lightbox.
    * **Contact.exe:** Outlook Express-inspired form integrated with Formspree.
* **Website-First Design:** Fully responsive floating window system for desktop and mobile.

## Project Structure
- `index.html` - Main OS Desktop structure
- `style.css` - CSS overrides and OS styling
- `script.js` - Windowing logic and event handlers
- `/img/icons/` - Asset directory

## Setup
1. **CV Download:** Ensure `KyleDungo_CV.pdf` is in the root directory.
2. **Contact Form:** Update the Formspree endpoint in `script.js` (`https://formspree.io/f/mdajakey`).
3. **Images:** Replace `img/KyleDungo.png` for your profile and project thumbnails in `index.html`.
